1. 选择或新建 Workspace

在左侧 Project Workspace 选择已有目录，或添加一个新目录。然后在目标目录的右键菜单选择「在终端打开」。

正在读取当前 Workspace…

初始化在终端当前目录生成工程文件；DevKit 不维护另一套隐藏项目目录。

2. 在 Workspace 终端初始化项目

muse search pptx
muse search pdf
# 未安装的能力先运行 muse install <插件ID>
muse init --name ppt-pdf-explainer --capability pptx --capability pdf

命令支持重复指定依赖能力；多个匹配时使用完整合同 URI 选择。已安装能力和在线市场共用搜索入口，安装仍由 Host 校验并请求授权。

3. 使用 Workspace 编辑器或 Agent 开发

直接编辑生成的 main.js 和 README.md。项目配置、依赖锁及全部源码在当前 Workspace，可交给已安装的编辑器和 Agent 插件处理。

muse check
muse dev
# 在应用内选择资料、授权能力并运行，关闭预览后：
muse report
muse pack
muse submit

调试使用独立 View 与资源授权。代码或依赖变化后旧报告失效；提交进入待审核，不自动上架。
