# GenOffice PDF 壳逐区台账

参照截图约为 1992×1248 桌面深色界面，实际行为以 [`apps/pdf/src/renderer/App.tsx`](../../genoffice-pptx/vendor/genoffice/apps/pdf/src/renderer/App.tsx) 和相关组件为准。`RIBBON_TABS` 是「开始、注释、编辑、页面、视图」，另有「填写表单、表单设计」上下文标签；保存/撤销/重做在快速访问区。目标为视觉与交互逐项对齐，不引入 GenOffice 的 PDF.js 文档模型。每项在产品包中有稳定 `controlId` 和 `commandId`；具体文案、图标及位置由签名资源声明。

| 一级区域/标签 | 源码可见的二级组与入口 | 首轮目标 | 接口归属与门禁 |
| --- | --- | --- | --- |
| 快速访问 | 保存、撤销、重做；未保存/保存失败、只读、XFA 提示 | 外观与状态同步 | 保存 Host+内核；撤销/重做内核。状态来自会话快照 |
| 开始 | AI 助手/总结/要点；高亮/下划线/删除线；编辑文字/插入文字；PDF 转 Word/Excel/PPT/Markdown/HTML；页码/缩放/适应宽度/适应页面；搜索、打印、导出图片、属性 | 全部入口和分组；G1 启用导航、缩放、搜索、属性，其他按能力开放 | 转换、AI 为显式扩展；编辑/批注为 core；打印/导出为 Host+core |
| 注释 | AI 审阅；标记；墨迹/矩形/椭圆/箭头/便签；涂黑；手写签名/证书签名/签名面板；颜色 | 保留层级、工具选中态与快捷操作 | 批注、涂黑、签名由 core；安全性未通过前禁用涂黑与证书签名 |
| 编辑 | 编辑/插入文字、插图、编辑图片、水印/图章 | 入口和编辑模式切换 | 文字依现有 ABI；图像、水印、图章需新 core API |
| 页面 | 左/右旋、全部旋转；删页、抽页、插 PDF、插空白、替换；裁剪、纸张大小；倒序、拆分 PDF、合并 PDF、合并页面、分割页面 | 入口/对话框/页面选择交互 | 页面组合先走现有 API；不保真输入必须拒绝；其余逐项扩 ABI |
| 视图 | 缩略图/大纲、单页/双页、夜间模式；页码、缩放和适应模式 | G1 完整启用已有视图操作 | Flutter 视图状态；大纲需要 core 返回书签树或显式降级 |
| 填写表单 | AI 填表；添加文字/勾/叉；前后字段；签名/图片；完成检查 | 上下文标签、字段导航与禁用态 | 表单数据由 core；AI 为显式低频扩展 |
| 表单设计 | 文本、日期、复选框、单选框、选项、签名六种字段工具；连续放置、预览、自动识别、排列、删除 | 上下文标签与多级工具面板 | 字段结构/写回由 core；自动识别可为显式扩展，结果由 core 校验提交 |

**菜单与弹层核对清单**：开始→PDF 转换→五种目标；高亮和绘制颜色→Office 色板（10 列主题色、5 行明暗色、标准色、更多颜色）；注释→签名/涂黑确认；页面→抽取/替换/拆分/合并/裁剪的选择器和确认页；视图→布局与适应模式；表单设计→字段类型、属性与排列。源码中的 Ribbon“排列”是单层 11 项下拉，且选中至少两个字段后才启用；“水印”直接打开对话框。`0.1.3` 已删除此前虚构的“水印/图章”子菜单及分组排列子菜单，签名包声明完整色板、真实排列顺序与禁用条件。其余选择器、动态项和确认对话框列入后续迭代。动态项（最近颜色、签名、字段、页数）须从 Host/core 只读 Provider 获取，包不存文档数据。每个叶节点测试：可用条件、键鼠触控、Esc/返回、禁用说明和真实命令结果。截图只显示「开始」页，其他菜单以源码台账为准。

## 中间内容区与底部状态栏

### `0.1.1` 对照结果

| 区域 | 已落地的源码对应结构 | 仍需验收的差异 |
| --- | --- | --- |
| 顶部标签和 Ribbon | 7 标签、83 控件、页码/缩放组合、高亮分体按钮、45px 平板紧凑带；签名资源决定组布局 | GenOffice 原 SVG 图标、悬停和选中态、快捷键及部分上下文工具状态 |
| 中央页面与侧栏 | 同一产品会话渲染页面和缩略图；34px AI 轨道、150px 可拖动侧栏、按页面比例的缩略图、右键/长按页菜单 | 复杂文档重绘、缩略图编辑实时预览、页拖拽重排、大纲数据、AI 面板 |
| 底部状态栏 | 24px 桌面栏仅跨文档区；页数、缩放按钮、滑块与百分比连接实际视图 | 保存/只读/签名等会话状态以及各 DPI 的截图阈值 |

右键菜单中的删页和抽页通过显式 `pageNumber` 参数进入产品会话；旋转及插页在当前 ABI 未支持时保持禁用。菜单声明位于已签名的产品资源，Flutter 只解释菜单和发送版本化命令。

1. 左侧有可收起的 AI 轨道，以及缩略图/大纲侧栏；宽度可拖动。缩略图保持原页长宽比、按可见区延迟渲染，当前页橙色描边，页码居中；拖拽可触发重排，但需内核实际支持且保真门禁通过。参照 [`PdfThumb.tsx`](../../genoffice-pptx/vendor/genoffice/apps/pdf/src/renderer/PdfThumb.tsx) 与 `App.tsx` 中 `pdf-thumbs`。
2. 中央深灰画布、白色页面、页间距、滚动、页面占位、文字选择/链接/批注/表单浮层。以产品会话的整页/区域渲染与文字坐标为基础，Flutter `PdfViewer` 作为**显示适配器**；页面覆盖层只保存临时手势状态，提交后以核心重新渲染。不得同时从 PDF.js 和产品会话绘制可编辑 PDF。
3. 底栏左侧“第 n 页，共 m 页”，右侧减号、缩放滑块、加号、百分比；值来自 Flutter 视图状态和 core 页数。保存状态、只读/错误也可出现在顶部，不与底栏页数混淆。

## 响应式行为与验收视口（设计目标）

| 视口 | 布局目标 | 交互方式 |
| --- | --- | --- |
| ≥1200 px 桌面 | 七标签的完整 Ribbon、可拖动侧栏、连续页面、底栏完整 | 键鼠、快捷键、右键、独立/内嵌窗口一致 |
| 840–1199 px 平板/窄窗口 | Ribbon 组压缩并横向滚动；侧栏可收起；双页可降单页 | 触控与键鼠兼容，所有入口可达 |
| 600–839 px 折叠屏 | 主要工具在一行，其他进入分组菜单；侧栏改抽屉 | 展开/折叠不丢当前页与缩放 |
| <600 px 手机 | 顶部紧凑标签或“更多”页签，工具以底部抽屉逐级展开；单页画布，底栏简化页码/缩放 | 点击区域至少 44×44 dp；长按与系统返回可退出子菜单 |

断点是首版实现假设，最终由设备截图与可用性测试调整。折叠屏使用可用窗口宽度而非设备物理宽度。键盘/屏幕阅读器应读出按钮名、状态、页码和不可用原因；放大字体时不能裁切页码和菜单。视觉验收以固定样本、固定 DPI/字体/主题的截图对比；行为验收需要实际打开 PDF、执行命令、导出重开，不能以按钮截图代替。
