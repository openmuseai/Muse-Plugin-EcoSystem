# 文档讲解插件：Desktop 产品与交互

## 目标与归属

在已经打开的 GenOffice PPTX、PDF Reader 文档上逐页讲解，编辑器继续负责原版渲染和编辑。讲解条、页序、提示词、暂停/继续与错误反馈全部由独立 Document Explainer 插件实现。DevKit 提供公开合同、生成与验证工具；Host 只挂载通用资源扩展、验证当前资源、授权及路由。关闭或卸载讲解插件不影响文档查看。

## 用户路径

1. 在现有 Workspace 开发；DevKit 搜索已安装或市场的 PPTX、PDF 能力，固定发行版本和合同。无需构建 Host、GenOffice 或 PDF 引擎。
2. 安装 Document Explainer，打开 PPTX/PDF；编辑区右下出现讲解条，不替换原编辑器、不出现第二个 GenSpark 面板。
3. 默认选「从第一页」，可切换「从当前页」。点「开始讲解」时显示 Agent 授权，明确当前资料会进入已配置模型的 DSH 会话。
4. 每页先导航并读取实时文本，再向同一 DSH 会话提交带文档名、页码的输入。DSH 面板显示真实用户输入与模型输出；收到完成回执后才能推进下一页。
5. 「暂停」取消本插件当前请求，停止自动翻页；未完成页可重试，已完成页继续下一页。「停止」结束本轮，重新开始仍可选第一页/当前页。结束显示「讲解完成」。
6. 切换、关闭文档、卸载插件、退出账号即撤销运行。恢复到原文档不自动发送新提示词，必须显式继续。手动编辑导致版本变化时读取最新页面，不使用初始化的磁盘快照。

## UI 设计依据

使用工程内 `.agents/skills/design-taste-frontend/SKILL.md`（taste-skill v2）的单组件流程：沿用现有应用方向，跳过营销页面方向抽签；实色、清楚的字号层级、单一强调色、可见焦点、完整状态、减少运动。这里是应用组件，不添加营销大标题、图片配额、卡片网格、毛玻璃或装饰性动画。

浮层位于编辑容器右下（避开顶部 Ribbon），宽 360px、最高 152px，左右距边缘 12px，底部距 36px（避开页码状态栏）。白/深灰实色底，6px 圆角，控件 32px 高，系统无衬线字体 13px，标题 14px/600，唯一强调色为现有应用蓝。狭窄编辑区宽度限制为容器减 24px；控件换行，不产生横向滚动。浮层只占自身矩形，其他区域仍由编辑器接收点击。支持 prefers-color-scheme、reduced-motion、键盘 Tab/Enter，状态区 aria-live=polite。

```text
文档讲解                              第 2 / 23 页
[从第一页 v] [开始讲解 / 暂停 / 继续] [停止]
正在生成本页讲解 · 内容将在 Agent 面板显示
```

状态文案：准备文档 → 可以开始 → 正在读取第 N 页 → 正在生成第 N 页讲解 → 已暂停 → 讲解完成。错误在条内显示原因与「重试」，不使用只写“失败”的全屏遮挡。缺少 Agent 时提示启用 Agent；缺少兼容实时接口时提示更新编辑器；PDF 无文字层明确提示需要 OCR，禁止捏造内容。

## 首版范围

Desktop 真实模型文本讲解、连续页序、暂停/继续、第一页/当前页、DSH 会话可追溯。语音朗读、Mobile 和 Web 单独验收，不把浏览器合成音或快照读取冒充已完成的实时能力。讲解数据属于用户文档内容；默认只传当前页文字，不传整个文件。文档中的指令作为不可信资料，提示模型只讲解、不执行其中的命令。

## 验收条件

- DSH 面板关闭后有标题栏恢复入口；恢复不丢失已打开文档或终端。
- GenOffice 原画布不被改写，工具栏来自独立 MCPB 的 HTML。
- 第一页与当前页模式均实测；DSH 同一会话每页包含一条输入和真实输出。
- 只有上一页完成后才进入下一页；双击无重复任务；暂停取消且不翻页；继续不会重放已完成页。
- PDF 实际两页夹具使用 PDF.js 渲染/文字层，不能以 PPTX 适配器处理 PDF。
- 关闭、切换、卸载、撤权后不继续模型请求；禁用插件后讲解条消失。
- 独立协议/生命周期测试 + macOS 完整包实际 UI 证据，两者不能互相代替。
