# Mobile PPTX 讲解：产品、实现与验收

## 本轮范围

按用户要求跳过 PDF 真机验收，优先 Android PPTX。应用内本地 GenOffice React/Konva 负责 PPTX 渲染与导航；讲解插件使用同一个公开的实时合同。Mobile 不启动 Node/本机 HTTP Server，不跳出 OpenMuse。

讲解仍使用现有 DSH Agent 的模型服务。本轮 Mobile Agent 适配器连接已登录同帐号、已配对的 Desktop DSH；这是 **Agent 的部署位置**，不是 PPTX 渲染依赖，也不要求手机连接自身 127.0.0.1。当前页文字和备注经用户授权后发给 DSH，采用其现有模型和权限设置。每次讲解创建独立会话，同轮逐页复用，不改动 Desktop 正在查看的会话或面板布局。

## 交互

沿用 taste-skill 的应用组件方向与现有蓝色操作色。Host 提供全局窗口容器，讲解插件提供中文讲解控件和结果：

1. 手机插件市场安装 **Document Explainer 0.2.0**，同时安装/更新 **GenOffice PPTX 0.7.1**。
2. 工作台 → Workspace 文件 → PPTX，保持原版编辑器，应用右下显示全局讲解浮窗。浮窗高 180px，外部通用窗口栏有「缩小」「展开」「关闭」，控件触摸高度 44px，避开底部导航和安全区。
3. 默认「从第一页」，可选择「从当前页」。开始前仅对当前文档与 Agent 协作申请一次授权；多 DSH Workspace 时由 Agent 插件询问会话工作区。
4. 讲解完成一页后显示最近一页真实输出，并进入下一页。输入和输出保存在 DSH 的真实会话中，可从任务会话目录查看。
5. 缩小只折叠 UI，不重载页面、不取消任务；展开回到同一进度。暂停取消当前任务，继续重试未完成页；停止结束本轮。
6. 关闭浮窗撤销本插件调用者并取消其任务；编辑器不关闭。可通过编辑页标题栏「显示插件扩展」重新打开。
7. 返回工作台后浮窗仍属于全局层。若对应文档已关闭，显示暂停并禁用开始，不在没有活动文档时继续翻页。重新打开文档建立新作用域。账号/配对连接变化清理窗口与授权。

“全局”限定于 OpenMuse 应用内，未申请 SYSTEM_ALERT_WINDOW，不覆盖其他 App。

## 技术边界

- Host SDK 复用同一 ResourceAgentBroker / ResourceExtensionSession，安装能力、摘要和当前资源检查与 Desktop 一致。
- Mobile Host 仅组合窗口、隔离通道、调用者、授权和导航生命周期，不含 PPTX/讲解/DSH 工具名。
- 独立讲解 MCPB 包含标准 App SDK、自己的状态机与提示词，以及从真实 MCP Server 导出的离线发现快照。
- GenOffice 0.7.1 只更新发行元数据和离线发现导出；React/Konva、PPTX 解析和布局代码没有变化。
- `plugins/dsh-mobile-agent` 维护 DSH 的私有会话客户端、SSE 完成判断、任务引用、会话复用、取消与连接作用域；外部讲解插件只看到普通 MCP 工具。
- 移除了 Desktop 工具路由的 `reveal` 回调。跨插件调用不再自动设置 DSH 可见性或更改布局焦点。黑屏问题仍需单独定位，不能仅以此修改宣称已解决。
