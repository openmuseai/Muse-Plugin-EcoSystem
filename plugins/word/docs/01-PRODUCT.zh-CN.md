# 产品范围与体验

## 产品定义

Word 是一个可安装、可停用、可升级、可卸载的 OpenMuse 产品能力。安装包交付功能区、命令与快捷键、模板、字体资源和低频扩展。离线安装完成后，已安装版本可在无网络状态下打开已授权的本地文档。文档文件、临时编辑状态和历史版本由 Host 与 `word-core` 管理，不放在插件资源目录。

`word-core` 和 `word_editor` 使用同一源代码树分别构建到 Desktop、Mobile、Web。插件安装控制产品入口与资源版本；Mobile 的原生可执行内核和 Flutter 编辑表面可以预装在 Host。Desktop 允许 Host 窗格内嵌和独立原生窗口，两种形态共用编辑器源码。Web 采用 Flutter Web 编辑表面与 Rust WASM 内核；WASM 是浏览器执行目标，不是插件协议。

## 用户流程

1. 用户从市场查看 Word 所需的 Host/内核 API 版本、包大小、签名发布者、离线能力和所请求权限。
2. Host 下载或导入包，验证 Registry 包 SHA-256、发布者 Ed25519 签名、所有资源摘要及合同，再原子安装；离线导入需要同样校验。版本不兼容时保留现有可用版本。
3. 安装成功后，`.docx` 的“用 Word 打开”入口出现。能力协商决定可见命令；缺失的保存、编辑或模板能力不显示为可用按钮。
4. Desktop 可在 Host 标签页内编辑，也可打开独立原生窗口；同一资源同时打开时由 Host 管理写入租约和版本冲突。
5. Mobile/Web 下载后断网，仍能使用已安装资源和内核编辑；关闭再打开必须从持久文档恢复。在线市场只影响新安装与更新，不影响已安装版本启动。
6. 更新失败自动使用上一版本；卸载移除插件资源、能力入口和扩展授权，不删除用户文档。

## 本期插件贡献

| 类别 | v0.1.12 资源 | 运行条件 |
| --- | --- | --- |
| 功能区与壳层 | GenOffice Docs 风格的八个常规页签、五个上下文页签、63 棵菜单树、快速操作、工作区与状态栏声明；完整视觉与功能按 G0–G5 迭代 | `word_editor` 提供通用原生 Flutter 解释器；无能力的命令叶节点置灰 |
| 命令 | 打开、保存、撤销、重做、粗体、斜体、下划线、缩放、字数统计 | 通过版本化命令接口映射到 Host、内核、编辑表面或扩展 |
| 快捷键 | Desktop/Web 的 `Primary+...` 声明 | Host 系统快捷键优先；输入法组合期间不触发冲突命令 |
| 模板 | 会议纪要、工作报告的结构化块资源 | 内核支持新建和模板应用后启用 |
| 字体 | 字体目录与回退顺序 | 当前无捆绑字体；未来仅加入已获再分发许可的字体 |
| 扩展 | 显式字数统计 | 取得用户授权的文本快照时调用，不订阅逐字输入 |

`features.json` 将编辑、保存、模板与字数统计默认关闭。它们需要相应能力通过认证，再由发行配置明确开启。`word.open` 与 `word.view` 也必须经过 Host 实际能力协商；默认开启不表示内核当前已达到产品质量。

## 非功能要求

- **文档一致性：**唯一可变文档模型在 `word-core`；插件不能持有第二份可编辑文档树。命令包含会话与基准修订号，保存需要内核导出和 Host 原子提交。
- **输入性能：**光标、选区、输入法、逐字编辑、可视区排版与页面绘制不经过 MCP、Node、QuickJS 或插件命令服务。扩展只在用户显式操作时执行。
- **离线：**字体、模板、功能区和扩展代码均来自已校验本地包；任何必需资源缺失时安装失败。Web 需要服务工作线程或等效离线缓存及持久文档存储。
- **安全：**插件不读取任意文件路径，资源由 Host 授权；扩展接收最小范围快照，预算受限。签名公钥由 Host 管理，不随包自报即信任。
- **可访问性：**Flutter 编辑表面负责键盘焦点、语义节点、屏幕阅读器和移动端输入法；插件提供本地化标签与快捷键提示。

## 本期之外

插件仓库不复制 Wordcraft egui 代码、`word-core`、FRB 绑定、Flutter Widget 或 DOCX 写入器。协作编辑、云同步、宏执行及完整 Word 功能兼容需要独立合同和验收；本插件不会用“已安装”掩盖内核未实现能力。
