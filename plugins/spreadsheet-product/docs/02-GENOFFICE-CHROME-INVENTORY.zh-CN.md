# GenOffice Sheets 壳清单与响应式设计

## 参考边界与视觉基准

主要来源：[`ExcelShell.tsx`](../../genoffice-pptx/vendor/genoffice/apps/sheets/src/renderer/ExcelShell.tsx) 的 Ribbon/工作区/状态栏，[`styles.css`](../../genoffice-pptx/vendor/genoffice/apps/sheets/src/renderer/styles.css) 的布局、颜色和紧凑模式，及 [`App.tsx`](../../genoffice-pptx/vendor/genoffice/apps/sheets/src/renderer/App.tsx) 到 Shell 的状态/命令传递。截图为视觉验收样本，不是源码或可执行 UI。复刻信息层级、可达性、交互反馈和几何比例；图标、商标、字体和素材使用具备再分发授权的 OpenMuse 资源重新绘制。

桌面参考量测：标签行约 35px，标准 Ribbon 80px，紧凑 Ribbon 48px，收起的 AI 侧轨 34px，状态栏 24px。Ribbon 横向可滚动，保留可见的细滚动条。状态栏只跨工作表内容列，AI 侧轨延伸到窗口底部。活动标签为绿色文字和接近文字宽度的下划线；截图使用深色主题，必须同时实现亮/暗主题 token。`ExcelShell` 仅挂载 `#univer-container`；编辑区内的公式栏、列/行标题、虚拟网格、对象图层和工作表标签要由我们的 Flutter 表面实现。

## 顶部 Ribbon 信息架构

常驻 7 标签按 GenOffice 顺序：**开始、插入、页面布局、公式、数据、审阅、视图**。无常驻“文件”标签；保存/另存/撤销/重做/自动保存位于顶端快速访问区，文件操作还在系统菜单或 Host 入口。依选区出现 **图表设计、表格设计、形状格式、图片格式** 4 个上下文标签，失去选区时自动退回常驻标签。

| 标签 | 源码中的一级组（应按顺序呈现） | 必须覆盖的二级入口与状态 |
| --- | --- | --- |
| 开始 | AI、剪贴板、字体、对齐、数字、样式、单元格、编辑 | 选择性粘贴、边框/填充/字体色、方向、合并、数字格式、条件格式、插入/删除/格式、排序/筛选/查找；加粗/对齐/格式随选区回显 |
| 插入 | 表、插图、复选框、图表、迷你图、筛选器、链接、批注、文本、符号 | 表和数据透视表、图片/形状、图表类型/推荐图表、切片器、超链接、文本框、函数符号等菜单 |
| 页面布局 | 主题、页面设置、调整为合适大小、工作表选项 | 主题/颜色/字体、页边距/方向/大小/打印区域/分页、缩放与网格线/标题打印开关 |
| 公式 | 函数库、定义名称、公式审核、计算 | 插入函数/自动求和/函数类别、名称管理、引用追踪、显示公式、重算选项 |
| 数据 | 数据透视表、获取数据、排序和筛选、数据工具、预测、分级显示 | 外部数据/文本分列、排序/筛选、删除重复项/数据验证、预测与假设分析、组合/分类汇总 |
| 审阅 | 校对、语言、批注、注释、保护 | 拼写/翻译、批注与注释菜单、工作表/工作簿保护、允许编辑区域 |
| 视图 | 工作簿视图、显示、缩放、窗口 | 普通/分页预览、公式栏与标题开关、缩放预设、冻结窗格/窗口管理 |
| 图表设计 | 布局、类型、数据、图表操作 | 图表元素、快速布局、切换行列、选择数据、删除图表；仅图表选中时出现 |
| 表格设计 | 表属性、工具、样式选项、样式 | 名称/范围、汇总行、表样式画廊；仅表选中时出现 |
| 形状格式 / 图片格式 | 形状样式、排列、大小等上下文组 | 颜色、层级、对齐、旋转、尺寸、图片相关操作；按对象类型出现 |

二级/三级弹出菜单不能压在网格裁剪区域内；使用 Host/Flutter overlay，保证键盘焦点、Esc/返回关闭、方向键和触控滚动。M0 生成逐项台账：源码位置、产品 ID、菜单路径、参数、选区条件、内核能力、状态 `ready/planned/blocked`、禁用原因与验收用例。以上表格是信息架构，不代表每项已由 GridCraft 或 `ss-core` 接通。

## 中间与底部

从上到下：名称框（A1/命名范围）→ 取消/确认/`fx` 公式栏 → 可滚动网格（行列标题、冻结分割、选区/填充柄、图表/图片对象图层）→ 工作表标签栏（新建、重命名、排序/隐藏、横向溢出）→ 24px 状态栏（状态文本、选区聚合统计、视图切换、缩放条与百分比）。公式输入与单元格原位输入只能写同一个 Rust 会话；输入未提交时 Ribbon 切换和系统返回要遵守一致的提交/取消规则。页面布局/分页预览属于同一个工作簿视图状态，不能引入独立的渲染模型。

## 响应式规则

按实际可用宽度和输入方式选择密度，不按设备名硬编码。安全区、屏幕键盘、折叠铰链和系统文字缩放都计入可用区；网格始终获得最低交互空间。以下宽度为首版测试点，可由测量结果调整。

| 可用宽度 | 顶部壳 | 编辑区与工作表 | 底栏/侧栏 |
| --- | --- | --- | --- |
| ≥1200dp 桌面 | 35/80px 标签+双层 Ribbon，完整文字与组，横向滚动 | 公式栏常显；网格虚拟化，鼠标/键盘完整功能 | 24px 完整状态；AI 轨道 34px，可展开为侧栏 |
| 840–1199dp 窄桌面/横屏平板 | 35/48px 标签+紧凑 Ribbon，图标优先但可访问所有菜单 | 公式栏可压缩，表签横向滚动 | 状态保留缩放/保存；AI 改抽屉 |
| 600–839dp 平板/展开折叠屏 | 标签可滚动，Ribbon 按组分页或横向滚动，触控目标至少 44dp | 公式栏单行可展开；网格维持冻结区；铰链分隔可放右侧检查器 | 统计/高级入口移入“更多”；状态栏不遮网格 |
| <600dp 手机/折叠屏外屏 | 常用命令条 + 标签抽屉/底部命令面板，保持 7 标签与全部菜单可达 | 名称框和公式栏压缩；点按编辑、拖柄选区、输入法避让、表签横滚 | 状态压缩为保存/选区/缩放，详情从抽屉进入 |

窗口缩放时保持活动单元格和正在输入的公式，不重建工作簿会话。折叠屏跨铰链先保证单区可用；双区布局作为增强，不是首版依赖。无论在哪个断点，Ribbon/状态栏都只发命令或显示会话快照，不参与单元格绘制热点路径。

## 视觉和交互验收基线

固定截图：1365×860 深色桌面、1024×768 窄桌面、834×1112 平板、390×844 手机、展开/折叠两种窗口，以及 200% 字体缩放。比较标签顺序、组顺序、间距、颜色、菜单层级、网格起点、公式栏、表签和状态栏；差异图记录到报告。触控、键鼠、屏幕阅读器分别跑菜单可达性。视觉验收和功能验收分开：被禁用的未接内核命令仍需有正确位置及说明，不能以截图相似替代编辑成功。
