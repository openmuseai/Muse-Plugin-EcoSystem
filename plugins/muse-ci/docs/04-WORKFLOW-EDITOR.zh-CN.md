## 主视图

Web/Desktop 默认进入流程画布。阶段从左至右排列，节点在阶段内纵向堆叠；画布支持空白区拖动平移、滚动、缩放、适应宽度与 1:1。同一列按显式依赖进行稳定拓扑排序，上游始终在下游上方；同列依赖用纵向连线表示。没有依赖的节点可以并行，卡片位置不产生隐式依赖。跨列同样只检查显式上游，不把整列完成作为下一列的启动门槛。

Mobile 使用同一份流程定义，改为阶段分组的纵向节点列表，保留添加、配置、日志、产物和重跑入口，不强迫手机操作大幅二维画布。旧版交付概览与计划页面继续保留；节点级配置、历史与重跑以本编辑器为准，旧版交付级演示不替代节点执行事实。

## 节点类型和组成

| 类型 | 用途 | 当前原型 |
| --- | --- | --- |
| AI 任务 | 目标、Skill、允许工具、输入材料 | 固定配置后生成明确标记的模拟结果 |
| 检查节点 | 功能、依赖、隐私、来源等验收 | 成功/失败、报告、重跑与历史 |
| 构建节点 | 平台构建及候选物 | 示例报告；没有真实二进制 |
| 人员决定 | 范围、产品或验收决定 | 等待用户记录本地决定，不自动通过 |
| 交付节点 | 组织变更、检查与审核材料 | 示例产物与依赖验证 |

节点卡片显示名称、简短说明、Skill、材料数、状态和最近尝试；底部有日志、产物和运行/重跑。颜色同时配合文字/图标；过期与失败分开，不把旧产物显示为最新有效结果。

## 编辑交互

| 操作 | 方式与结果 |
| --- | --- |
| 添加节点 | 工具栏或任意阶段底部添加；选择类型与阶段，打开配置抽屉 |
| 添加阶段 | 输入阶段名，生成独立阶段身份 |
| 移动节点 | 拖动卡片到另一个节点前，或阶段空白区末尾；也可在配置内选择阶段。同列不能把下游拖到上游前面；改阶段后按依赖重新排序 |
| 并行启动 | “运行就绪节点”启动当前待执行/过期且上游均成功的节点；无依赖节点可同时运行，失败节点需显式重跑 |
| 添加依赖 | 点击上游右侧连接点，再点击下游左侧连接点；配置内也有依赖选择 |
| 删除依赖 | 点击连接线并确认；键盘 Enter/Space 也可打开确认 |
| 配置节点 | 点击标题或设置图标，右侧抽屉编辑；Mobile 全屏抽屉 |
| 删除节点 | 明确确认后移除节点和边；下游旧结果标记过期 |
| 导出流程 | 下载当前浏览器的完整示例定义及历史 JSON；无服务器上传 |

本地原型最多 60 个节点，尚未实现从 JSON 导入、任意自由坐标布局、多用户同时编辑或后端并发调度。卡片拖拽用于阶段/顺序调整，不改变已有依赖。

## 配置抽屉

1. **基础配置**：名称、类型、阶段、说明、目标、上游依赖、超时、重试上限、产物名称。
2. **Skill 与工具**：从预置目录选择，或添加自定义引用；保存所选能力。自定义引用明确标为未验证，不自动获取权限。
3. **输入材料**：文字材料、本地文件引用和上游产物。文件仅保存名称、大小及类型，不读取正文、不上传。上游引用记录 nodeId、attempt 与产物序号。
4. **执行与产物**：选择历史尝试，查看固定输入、配置版本、日志和对应产物；打开并下载 JSON 示例。日志与产物按 Attempt 隔离。

切换配置 tab 保留未保存输入。新选择的上游会立即出现在材料引用选项里。保存校验目标、数字范围、阶段和 DAG；循环连接、重复连接、自依赖被拒绝。运行/等待人员决定期间锁定流程结构修改，避免改变正在使用的输入。

## 依赖、并行与单节点重跑

例：同列 A → B，另有无依赖节点 C，则 A 与 C 可以并行启动；B 等 A 成功后才就绪。增加依赖后立即重排显示，移除依赖后不再串行等待。批量启动只取点击时的就绪集合；本地原型不会自动启动后续一轮，需再次点击。正式调度器应在上游完成事件后重新计算就绪集合，并受 Runner 容量、资源锁及预算约束。

- 仅当所有直接上游均为当前成功状态时可运行；缺失、失败、运行中或结果过期都会阻止。
- 每次重跑新增 Attempt，固定节点配置版本、Skill、工具、材料和上游尝试引用，保留旧日志与产物。
- 修改执行配置、依赖或重跑上游，使受影响下游结果过期，不默认重跑整个流程。
- 仍引用上游旧 Attempt 的材料不能用于新运行，必须重新选择。
- 普通节点以短暂的本地模拟演示运行与完成；人员决定节点停在等待状态，需用户显式记录。
- 页面重载中断未结束的本地模拟，恢复后标记中断失败并允许重跑，不假装后端仍在执行。

当前“自动重试上限”和“超时”是可配置并固定到输入的策略值；原型尚无真实重试/超时调度器，不据此声称具有执行隔离。

## 实现边界

- `web/graph-model.js`：有向无环图、依赖检查、过期传播、配置与 Attempt 状态。
- `web/workflow.js`：画布、SVG 连线、连接/拖拽、抽屉、材料与产物。
- `web/workflow.css`：分阶段样式、可读性、缩放及 Mobile 列表适配。
- 浏览器独立存储键：openmuse.muse-ci.graph.v1。正式服务接入后使用版本化图及后端事实，不能把此键当可靠执行数据库。
- 不添加 CI 专用 Host API；后续工具仍通过通用 MCP 与 openmuse.ci/1 合同访问执行后端。
