## 产品过程

产品定义 → 架构设计 → 开发与构建 → 检查 → 人员验收 → 发布准备。产品阶段包含独立的产品稿、UI 稿节点，两者无依赖时并行；架构节点依赖二者。每个材料记录正文/版本/摘要；执行尝试固定其输入，修改产品、UI 或架构会使相关下游结果过期。保存设计不等于已实现；任务必须同时关联功能、UI 入口和验收证据。

产品稿应包含用户、目标、范围、不做项、功能编号、验收条件。UI 稿应包含页面/节点结构、Desktop/Mobile 交互、空/错/等待状态和可运行 UI artifact。架构稿应包含边界、合同、真源、DAG 调度、输入失效、权限、执行隔离及恢复。AI 产出只能作为版本化提案；执行与验收读取确定性记录。

## 实施顺序与验收

| 工作包 | 产品/UI | 代码交付 | 验收 | 状态 |
| --- | --- | --- | --- | --- |
| MC-01 产品过程 | 产品稿/UI 稿/架构节点，配置与材料 | 节点模板、默认 DAG、演示数据迁移 | 同列拓扑、无依赖并行、设计修改传播 | 开发闭环通过 |
| MC-02 统一合同 | 七个页面使用同一项目/计划/Run | Schema、服务端图模型、版本冲突、命令幂等、事件游标 | 不同客户端一致；损坏/旧输入被拒绝 | 开发闭环通过 |
| MC-03 持久执行（开发实现） | 运行/暂停/恢复/取消、等待决定 | PostgreSQL、事务命令/Outbox、Temporal、worker | 重启恢复、重复命令不重复执行、取消收敛 | 开发闭环通过；边界见验收文档 |
| MC-04 节点能力 | Skill/工具/材料/日志/产物 | Provider 注册表、固定输入、实际受控检查、摘要产物 | 真实进程退出码、输出摘要、失败保留、重跑 | 开发闭环通过；边界见验收文档 |
| MC-05 AI 合同 | 目标→计划提案、输入接收方说明 | 可配置 DSH/MCP Provider；无 Provider 明确阻塞 | 不以模板输出冒充模型调用；数据授权与预算校验 | adapter/合同通过；真实 Provider 待绑定 |
| MC-06 MCP 插件 | 通用 tools/resources、安装发行输入 | MCP server、MCP Apps UI artifact、标准本机包/远端发行锁 | 实际 MCP 握手/工具/资源、摘要与兼容检查 | 开发闭环通过；边界见验收文档 |
| MC-07 UI 接入 | 现有七页、配置抽屉、跨客户端同步 | 本地/服务/MCP adapter、统一状态订阅、连接错误 | 浏览器创建→设计→执行→报告→重跑闭环 | 开发闭环通过；边界见验收文档 |
| MC-08 功能验收 | Desktop/Mobile 页面、发布缺项 | 集成测试、恢复/隔离/幂等测试、证据报告 | 自动测试＋实际浏览器操作；不伪报商店成功 | 开发闭环通过；边界见验收文档 |
| MC-09 Host 通用能力 | 两端市场安装、可信后端、鉴权 | P01–P08 安装/会话/Auth profile | 实际 Desktop/Android/iOS 安装登录卸载 | 平台阶段 |
| MC-10 正式发布链 | 十二阶段/多渠道/凭据/设备 | 隔离 Runner、签名、渠道 adapter、可信审批 | 真机/真实渠道回执、reconciliation | 发布阶段 |

MC-01 至 MC-08 为本轮实施闭环；MC-09/10 不冒充已完成。首个可执行链路使用本机开发服务、独立数据库、真实 Temporal 和受限检查 Provider，端到端验证从浏览器和 MCP 发起到持久结果。生产接入复用同一合同，但开发身份不等同 GoTrue/OAuth 验收，开发 Runner 不等同生产隔离。

## 功能与 UI 验收矩阵

| 功能 | UI 入口 | 后端真源/合同 | 必验事实 |
| --- | --- | --- | --- |
| F01 连接与项目 | 设置、工作区、连接状态 | projects/list、项目 ACL、连接 capabilities | 未连接不派发；跨项目拒绝 |
| F02 目标/产品定义 | 总览、新建交付、产品节点 | project/create、plan/save | 目标/产品/UI 版本固定，重启后可读 |
| F03 计划和架构 | 计划、架构节点、依赖配置 | graph revision、AI proposal | 版本冲突拒绝，提案和实际执行区分 |
| F04 节点执行 | 画布启动/并行/重跑 | run/start、attempt snapshots | 显式依赖满足；真正并行；旧结果过期 |
| F05 控制 | 运行页 | run/pause/resume/cancel | 暂停不派发、取消后不再写成功 |
| F06/F09 决定 | 决定节点、运行阻塞 | bound decision、事件 | 输入变更使决定失效；客户端不能伪造真实发布批准 |
| F07 证据 | 日志/产物抽屉、证据页 | immutable artifact digest、attempt | 对应实际命令与输入；按尝试隔离 |
| F08 发布 | 发布页 | 十二阶段映射/缺项 policy | 没有签名/设备/渠道回执时保持阻塞 |
| F10 恢复 | 同一项目所有页面 | 数据库快照＋event cursor、Temporal | 另一客户端读到相同结果，关闭页面不终止 Run |
| F11 AI 数据 | 设置/节点能力 | provider recipient、data consent | 未配 Provider/授权则阻断；不伪造 AI 成功 |
| F12 插件生命周期 | MCP App 启动/关闭 | UI resource、发行摘要/连接 | 页面关闭不取消后端 Run；正式市场验收单列 |

## 验收命令与证据

后端：`cd Muse-CI && npm ci && npm run typecheck && npm test`。开发栈及端到端脚本在实施时提供。插件：`cd Muse-Plugin-Ecosystem/plugins/muse-ci && npm test && npm run build`。所有证据记录版本、真实执行方式与未接通环节。仅模型单测或响应式截图不构成端到端通过。
