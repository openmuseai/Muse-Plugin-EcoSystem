# Muse CI 交互规范

> 2026-11-19 更新：当前版本/需求双层流程、Step 规则、人工标过及 SmartDoc 文档协作以 [生命周期新规范](07-LIFECYCLE-AND-SMARTDOC.zh-CN.md) 为准。以下旧画布和原型记录作为历史基线保留。

## 节点画布更新

Web/Desktop 使用分阶段节点画布，编辑、能力配置、材料与执行记录详见 [节点交互规范](04-WORKFLOW-EDITOR.zh-CN.md)。下列交付总览、计划和运行页面属于保留的交付级演示；节点执行不依赖该旧演示状态机。

## 设计主线

以交付事实为主线：左侧选工作区域，中间看任务与证据，右侧处理决定。AI 建议与状态并列，但不能用聊天气泡取代计划和运行记录。当前项目“Mobile 文档依赖隔离与审核整改”源自工程任务；页面中的预算、报告和运行事件是明示的示例数据。

## Desktop 与 Mobile

Desktop 使用稳定侧栏、内容区与按需出现的右侧待决策区。Mobile 使用顶部标题、纵向内容和底部导航；设置、发布和项目切换从更多菜单进入。窄屏的阶段采用可选择列表，不压缩成十二个不可读标签；证据改为纵向行。

控件点击目标至少 44px，可见键盘焦点，支持 Tab、Enter、Escape。对话框锁定背景交互、初始焦点合理、关闭后回到触发按钮。prefers-reduced-motion 下去除位移动画。状态不能仅用颜色表示。

## 核心流程

| 入口 | 用户行为 | 页面反应与下一步 |
| --- | --- | --- |
| 新建交付 | 输入目标、类型和预算，提交 | 创建草案，转到计划；不隐式执行 |
| 保存计划 | 修改目标/预算后保存 | 增加计划版本；旧运行保留旧版引用 |
| 运行此计划 | 当前没有活跃执行 | 未连接先显示连接入口；已连接创建示例 Run 并转到运行 |
| 暂停 | 当前运行中 | 暂停新步骤，本地事件记录；恢复按钮可用 |
| 恢复 | 当前暂停且已连接 | 返回运行中，继续同一示例 Run |
| 演示下一步 | 运行中点击预览专用按钮 | 推进一个本地任务并生成示例事件，避免假装后台真实执行 |
| 取消运行 | 点击取消 | 对话框说明影响，确认后终态；取消对话框不改变 Run |
| 决策卡片 | 查看名称或数据授权问题 | 查看事实与选项，填写决定；记录为本地决定，不标为商店通过 |
| 证据行 | 查看报告 | 显示来源、状态和检查内容，可下载示例 JSON |
| 提审入口 | 前置不齐 | 展示具体缺项与去向，不提供可伪执行的提交按钮 |
| 连接后端 | 查看设置/连接弹窗 | 选择示例连接或断开；明确没有网络请求 |
| 重置演示 | 确认 | 清空原型专属本地存储，保留其他应用数据 |

## 状态定义

交付含 draft、running、paused、needs_decision、completed、canceled。界面文案为草案、运行中、已暂停、待决定、示例执行完成、已取消。

断开连接不抹去示例运行状态，但禁用需连接的控制，并提示重新连接。正式实现应读后端事实，而不是由客户端自行推定已暂停或完成。没有真实签名包、TestFlight 安装或平台回执时，发布阶段始终待完成。

示例计划的批准只表示范围决定已记录。AI 数据授权的同意只表示原型中的选择；实际授权必须明确接收方、数据类别及范围，后端变更时重新评估。

## 接入边界

原型使用独立本地 adapter；所有与 UI 数据变更有关的入口集中在状态模型，未来替换为 openmuse.ci/1 MCP tools。UI 不拼接 shell，不调用私有 Host 命令，不设置认证 Header。正式 Host 不支持时显示升级或不兼容，不自动改用开放联网网页。

错误显示在对应表单附近，保留用户输入；操作结果通过 aria-live 通知。用户输入按文本渲染，浏览器存储仅用于非敏感演示状态。真实项目内容与 token 不应沿用此存储方式。

## 同列节点与并行

同列依赖由上到下显示；有向边决定执行约束，拖动位置不建立依赖。无依赖或所有上游已成功的节点可并行启动。“运行就绪节点”只启动本次就绪集合，失败节点保留单独重跑入口。跨列没有默认整列屏障。依赖发生变化时重新排序，并使受影响的旧结果过期。

## 服务模式更新

七个页面现已接入同一服务端项目。产品稿与 UI 稿先并行，架构等待二者；流程配置、运行、事件、材料和产物均经标准 MCP tools。服务模式不在浏览器推进模拟状态；新建、决定和控制均显示接收/应用的区别。详细验证与保留的离线示例边界见 [实现说明](06-IMPLEMENTATION-AND-ACCEPTANCE.zh-CN.md)。
