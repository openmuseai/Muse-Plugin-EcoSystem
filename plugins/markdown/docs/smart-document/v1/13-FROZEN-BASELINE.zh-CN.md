## 2. 冻结的产品决议

1. 编辑优先：页头/共享、菜单、常用格式、连续内容、大纲、可关闭上下文面板。Agent 按需打开，复用 Host，不常驻挤占默认写作面。
2. 原生基础写作、真实协作与离线、评论、权限、来源、Agent 有界修改、至少一类真实 Office provider、受限数据集和应用样板按 SD-01–17 的限定范围交付。
3. 首版 heading H1–H3；H4–H6 的显示/schema 预留不等于首版编辑承诺。基础文字格式包括加粗/斜体/下划线/删除线/高亮/行内代码/链接，字号/颜色按三端能力表开放。
4. 内容顶层是并列对象；Word/Workbook/PDF/Dataset 可独立打开，嵌入只保存视图绑定，移除引用不删除来源。
5. 评论、历史快照、协作记录和在线感知分别管理；评论者不能提交正文更新，孤儿锚点不等于已解决。
6. Flutter 优先，Rust/Collab/Yrs 为正文领域与协作实现方向；服务端继续 Muse-Server/AppFlowy-Cloud；PDF 保留 C++/PDFium；其他 Office 内核继续复用。
7. 协作公共 contract/runtime 为 package，Cloud 为 provider/plugin，内容领域持有合并/锚点/undo/恢复。Everything is Plugin 不要求任意 native 能力运行时热安装。

其中技术方向冻结为实施约束；精确版本、协议字段、FFI、树操作映射和 schema digest 必须在 G0 获得证据后另行冻结，不能用本次产品冻结替代工程验证。

## 4. 快照与变更方式

快照目录包含规范副本、设计文件和 `manifest.json`。清单记录每个文件的大小/SHA-256、来源、基线及检查说明。Markdown 链接会调整为快照内指向或工作区的正确相对路径，因此快照文档摘要可以与工作副本不同；视觉源码保持逐字节一致。清单是本地完整性记录，未做外部签名，不替代 Git 提交或供应链证明。

校验：

```sh
python3 scripts/verify_baseline.py
```

在本 `v1` 目录运行。脚本只读校验，不重写基线；不会因重新跑浏览器检查而修改冻结截图。正式归档里的检查脚本输出应指定新的证据目录。

不原地修改快照。技术实现和等价的内部重构可在 [14](14-ENGINEERING-DESIGN.zh-CN.md)/[15](15-EXECUTION-PLAN.zh-CN.md) 持续细化；改变 P0/延期承诺、用户可见语义、权限、数据兼容或扩大范围时记录 CR，说明影响并形成新的基线版本。已有授权范围内的实现不反复请求确认。
