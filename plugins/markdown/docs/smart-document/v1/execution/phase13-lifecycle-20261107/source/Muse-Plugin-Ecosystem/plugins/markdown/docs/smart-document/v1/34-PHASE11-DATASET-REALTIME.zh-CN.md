# P11：独立数据库实时协作适配（开发中）

承接 [P8 中立实时协议](31-PHASE8-REALTIME-IMPLEMENTATION.zh-CN.md) 与 [P10 资源嵌入](33-PHASE10-EMBEDDED-DATASET.zh-CN.md)。P10 已归档 306 份文件，含 245 份自有源码快照；完整思源/协作门仍未通过。本轮不更改产品/视觉冻结，不复制一套数据库或 WebSocket 协议。

## 适配边界

数据库控制器保持原 Database/Row 为权威，提供有界、显式作用域的对象快照/远端合并能力；独立应用适配器复用 `muse_appflowy_realtime` 原 WS2 编解码、连接与 Yrs Awareness。根使用类型 1，独立行使用类型 4；在线状态绑定数据库资源及稳定 row/field/view ID，不能使用正文路径或文字锚点。Host 注入原账号/工作区绑定，URI/token 不进入资源、缓存、日志或 UI。

HTTP full-sync 继续用于明确接收、首次对象创建和修复，WS 消息只降低延迟。新行先通过既有 HTTP 边界注册，之后才能发布根中引用；不能向 WS 写一个未知 ID 并假定服务端完成了授权注册。Redis RID 仍不是持久收据，不实现新的隐式 outbox 承诺。

## 次序与容量

1. 先同步并订阅根，再根据已验证根中的稳定行 ID 订阅独立行。对未引用行不直接写入当前 Dataset。
2. 行早于根到达时，应用适配器仅作有界、短期暂存；根出现对应引用后，再经过原行 `database_id` 校验合并。过期/超量则丢弃暂存并通过 HTTP 修复，不能制造空行覆盖真实数据。
3. 根引用了未加载行，立即进入保守只读状态，恢复到完整授权行之前不允许结构修改。已移除的引用要释放其暂存、权限/订阅投影，不因旧对象状态永久锁死其他记录。
4. 所有接收串行化；本机持久化沿用原保存队列。内容快照不存在线成员、选中格、角色自述、token 或 WS 游标。
5. 连接恢复用原 state vector/HTTP 修复；反向重放、重复帧、非所属行、错误类型、保存失败和关闭中的回调都必须验收。

## 权限与界面

Host 的不可编辑上限与服务端新鲜能力取交集；暂停/恢复网络不能恢复写权限。服务端拒绝读后不再投影新内容，失去写权限后保留草稿但禁用写入口，删除状态不能被普通恢复消息清除。读取方仍可接收合法更新。根/行独立权限先采用保守范围，完整逐行授权与资源注册表另按平台领域计划交付，不把工作区成员权限冒充行级权限。

独立资源与文档内 Grid 使用相同适配器/会话。在线成员使用服务端归一化 UID 和 Host 可信名字；选中格/正在编辑是临时界面状态，不作为内容锁或用户角色证明。共享表格工具栏、单元格草稿及父/子历史边界沿用 P10；成员与远端选中格的界面在真实跨端回归通过后才开放。

## 开发与退出条件

先实现对象快照、合并和权限边界测试，再接动态根/行 WS2 与有界重排；随后接公开插件会话生命周期和共享 Grid 在线状态。每一层都复用当前原实现，禁止以单机事件广播替代真实 Cloud。

退出需要 Native/WASM 同一根/行双账号更新、读者接收、断开后追赶、新行乱序、缺失/外来行拒绝、同格/异格撤销边界、撤权与删除、原生与浏览器互通、独立窗口/嵌入真实 UI 和新进程恢复。此文档不是已通过声明；日期/五视图、即时分布式撤权、持久 ACK、评论/历史、Agent/Office 及 Android 仍保留在完整对齐计划中。

## 已实施边界与实际结果

控制器现有对象访问分成内容快照与仅状态向量的授权恢复入口。后者允许在拒绝读之后请求新鲜能力，但不返回缓存单元格数据。类型不匹配、未被根引用的对象及原行 `database_id` 不匹配均拒绝；合法根先到而行未到时立即只读。未加载行使用原 `StateVector::default().encode_v1()` 请求完整追赶，没有新建空白数据副本。

短期重排缓冲限制为 32 个行 ID、总 2 MiB、每行 4 帧、5 秒；仅在合法根关联后经过原行校验应用。断开/关闭清空缓冲，所有合并沿用原候选校验及序列化本机保存。只有实际核心状态改变才增加接收合并计数，忽略/重复帧不冒充有效编辑。

当前原 WS2 是工作区广播协议；客户端关注窗口默认前 128 个引用行，其他行靠 HTTP 修复。这不是已经实现协议级对象订阅或认证过的 1000 行交互容量，后续必须接入真实可见窗口和服务端订阅/速率边界。首次新行仍先走原 HTTP 注册，再发布根引用；接收方可以通过原根/行 manifest 完成新行引导。

`OpenMuseDatasetPlugin` 新增可选 realtime factory 并拥有关闭顺序，历史资源不创建连接。文档内与独立打开共用 DatasetSurface、DatasetRealtimeSession 和资源检查点。共享成员入口抽取到 `Muse-Client/packages/muse_collab_widgets`，保持原正文的样式与 key；成员面板在窄屏内滚动。表格单元格绘制按稳定 view/row/field 定位的远端边框；对话框打开/关闭只更新临时 editing 状态，不广播草稿文字，也不把它当锁或角色证明。

界面区分“实时连接正常”和 HTTP 接收确认不可用，不能把 WS 到达描述成服务端持久成功。实时状态不写内容/检查点。共享历史的键盘路由和完整多端 IME 仍待补齐；当前通过的是明确作用于子表格的撤销/重做控件，以及对话框草稿的前置条件保护。

- 真实 Guest 独立工作区 7 项：显式分别授予根 1/行 4 的 read，拒绝两类原始 WS 越权写并权威读回；同一连接升级编辑、降级后拒绝旧 writer、仅撤销行权限后拒绝新广播/HTTP、删除数据库根后保持终态。没有修改原合成用户在其他验证工作区的权限，没有借父引用授予行权限。
