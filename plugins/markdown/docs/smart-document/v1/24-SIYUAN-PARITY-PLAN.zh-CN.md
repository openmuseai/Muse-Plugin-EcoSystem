## 1. 对齐基准与范围

固定参考为仓库 `vendors/siyuan` 的 **d3af9d5782082b379d45a69eedf4ebcfe8ba6889**，`app/package.json` 版本 **3.8.9**，读取时工作区干净，未修改/切换该仓库，也不声称核验了最新远程版本。源码规范 [SY-FORMAT](../../../vendors/siyuan/docs/SY-FORMAT.zh-CN.md) 明确普通 Spec 2、Tabs Spec 3、表格富文本 Spec 4、Mindmap Spec 5、带 `/` 标题的 Spec 6，不能仅对齐段落/标题后宣称编辑功能一致。

## 2. 可执行台账

[功能对齐台账](siyuan-collaboration-parity.json) 包含 **36 项编辑能力 + 14 项协作能力**。每项保存：固定来源、主任务、实现状态、Desktop/Web/iOS/Android 验证状态、已知缺口、完成用例和证据。功能“已存在”与全部平台“已验收”分开。

```sh
python3 scripts/verify_parity.py
python3 scripts/verify_parity.py --require-complete
```

第一个命令检查台账结构/覆盖和来源，不能输出完整产品通过。第二个命令要求全部目标项 passed、无遗留缺口、全部要求平台通过并有证据；当前必须返回非零。Android 继续按用户已给出的“暂不安装，仅继续 iOS”限制保留未验收状态，这不降低最终多端门槛。

## 4. 下一批的具体技术任务

1. **树移动与锚点（T05）：** 当前类型命令保持 block/Y.Text/children 身份，但旧缩进、拖拽、部分上游快捷键仍可能 delete/insert。必须统一命令并测试两个成员同时移动、删除对方目标、循环父引用、同一块多父引用。不能仅复用 `move_block` 就宣布并发结构安全。先完成服务端串行校验/确定性冲突规则，再开放完整结构编辑。
2. **表格（T05/T08）：** 固定 cell/row/column 身份，单元格 rich text 与行列几何分别建模；补齐增删、选区、粘贴、合并/拆分和跨端 UI。当前 editor 包有 Table renderer，但直接开放其行列按钮不能证明协作安全；单元格并发与拓扑并发分别验收。
3. **附件/元素（T15/T18）：** 资源草稿、来源 ID、上传状态、权限、未知元素保留和 renderer 分开。图片不是把一个 URL 属性写入正文就算完整；视频/Office 由 provider 贡献，不嵌入任意未受限 HTML。
4. **实时与角色（T06/T10）：** 复用原 Cloud WS/session 机制，通用 package 承载会话/增量/awareness，文档插件提供 Y.Text relative anchor。presence 不写入正文快照；服务端裁决权限/TTL，客户端禁用按钮不能代替授权。
5. **评论/@/分享/历史（T10/T13）：** annotation 独立实体与权限；原 Cloud 当前的 published-view comment API 不能直接冒充私有文档块锚点评论。补充持久化服务、outbox、撤权、失效锚点和恢复屏障后接 UI。
6. **Agent（T11/T12）：** 使用稳定对象/块地址与真实读集，命令带前置条件和幂等键；所有入口共享服务端领域校验。当前 AI 样式保留，不计生成、修改预览或后台作业已经实现。
7. **格式保真（T19）：** 建立固定 SiYuan 源样本、命令序列、AST/呈现对照与原始包保留。支持读取未知字段仅是可取回，不等于可编辑保真；AV、SQL 嵌入、插件 HTML 等必须分别有能力与降级声明。

## 5. 停止扩大发布的条件

原始更新越权、结构合并破坏单父/无环、保存已报成功但重开丢失、评论恢复覆盖正文、Agent 过期修改仍被应用，均须优先修复并保留失败语料。所有“完整”标记由用例和完成门产生，不能由页面画完或同步状态变成绿色产生。
