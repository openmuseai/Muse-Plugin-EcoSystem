## 1. 定位与价值

智能文档是一张可协作的工作页面：用户在同一阅读流中写作、引用 Office/媒体、查看结构化数据、使用小应用，并与 Agent 共同完成可追溯的工作。页面中的外部对象可以独立使用，组合后仍保留各自权限和专业编辑能力。

核心价值：减少内容在文件、聊天、数据表和应用之间的反复复制；让 Agent 理解结构与来源并执行可靠操作；让团队能看见谁修改了什么、哪些已保存、哪些尚未共享。

## 2. 用户与核心场景

| 用户 | 工作目标 | 首版典型路径 |
| --- | --- | --- |
| 内容作者/知识工作者 | 写作、组织证据、保留引用 | 建文档 → 写块内容 → 插入 Office 页/图片 → 分享 |
| 项目负责人/协作者 | 共同维护报告与任务状态 | 编辑/评论 → 看板/表单 → 跟踪更新与版本 |
| Agent 使用者 | 基于材料生成并维护结果 | 指定范围与来源 → Agent 生成建议/提交 → 追踪冲突与来源 |
| Mobile 参与者 | 阅读、评论、短编辑、提交表单 | 最近打开 → 文档定位 → 评论/编辑/提交 → 看见同步状态 |
| 扩展开发者 | 添加元素、操作与文档应用 | 实现声明 profile → 兼容检查 → 安装 → 文档内使用 |

用户主线 A：项目周报含段落、任务表、固定 PDF 页与视频演示；多人更新正文，Agent 根据指定数据版本写总结。

用户主线 B：同一项目任务数据集在独立表格、文档看板和手机表单中复用；Agent 更新记录，所有入口可观察结果，不复制三份数据。

## 3. 产品原则

内容身份跨入口稳定；编辑结果可追溯；共享/本机保存状态真实；未知内容可保留；引用与复制行为明确；缺失能力可解释；Mobile 可以调整布局但语义一致。普通已授权操作不反复弹出确认，冲突、有损转换和删除来源对象必须按真实影响呈现。

内容编辑、协作连接和共享状态是不同能力：关闭连接不自动停用内容 plugin；缺失所需内容/状态引擎则按能力只读，不能承诺任意插件停用都不影响编辑。普通用户操作不暴露 engine/schema/协议选择器，插件管理只表达真实依赖与可用性。

## 4. 首版需求台账

P0 是 0.1 发布范围，P1 为后续增强；表中限定语也是验收范围。完整交互见 [05](05-UX-SPEC.zh-CN.md)，测试映射见 [07](07-ACCEPTANCE.zh-CN.md)。

| ID | 需求 / 优先级 | 用户可见行为与首版边界 |
| --- | --- | --- |
| SD-01 | 创建/打开/资源身份 P0 | 从资源中心新建、最近重开、重命名；同一对象可由独立入口和嵌入访问 |
| SD-02 | 原生块写作 P0 | 段落、标题、列表/任务、引用、代码、公式、基础表格；斜杠插入、Markdown 输入、格式工具与撤销 |
| SD-03 | 多人协作 P0 | 同段编辑、远端光标/在线人、作者来源；5 人目标，10 人压力测试；复杂跨领域拖放不开放 |
| SD-04 | 本机保存与离线 P0 | 正文本机持久、断网继续受支持编辑、重启恢复、重连补齐；数据集/外部动作离线仅草稿 |
| SD-05 | 评论 P0 | 锚定块/文本、回复、解决/重开；目标删除显示失效锚点，不静默迁到别处 |
| SD-06 | 引用/嵌入 P0 | 稳定块引用、来源跳转、基础反链；只读嵌入；失权/缺失/未下载有区别 |
| SD-07 | Office 同屏 P0 | 至少一类真实 Office provider 三端固定版本预览与来源标记，优先 PDF；Word/Excel 能力逐类开放 |
| SD-08 | 图片/视频 P0 | 上传/引用、图片展示、视频播放、尺寸/替代文本/标题；无专业剪辑/多人像素编辑承诺 |
| SD-09 | Agent 原生操作 P0 | 选区/文档范围、结构读取、生成建议/受权提交、作业进度/取消、冲突与来源；后台按委托范围运行 |
| SD-10 | 基础数据集 P0 | 文本/数值/日期/单选/布尔字段，记录 CRUD，表格/看板；对象级权限与在线事务提交 |
| SD-11 | 文档应用样板 P0 | 通过内置模板生成项目任务表/看板/表单/统计，复用同一数据集；不含任意代码生成执行 |
| SD-12 | 元素与界面扩展 P0 | 声明式元素/模板/菜单/工具栏贡献、签名/能力协商、未知元素占位；原生组件升级随应用版本 |
| SD-13 | 历史与恢复 P0 | 查看检查点、作者/Agent 作业、恢复正文且不覆盖旧离线草稿；外部依赖按固定版本重开 |
| SD-14 | 思源渐进兼容 P0 | 明确支持子集的显式导入、来源 ID/原包保留、未知载荷与损失报告；原生兼容入口继续可用 |
| SD-15 | 权限与分享 P0 | 已认证 workspace 用户的 view/comment/edit 能力；引用不增权；撤权停止后续写入 |
| SD-16 | 交换与备份 P0 | Markdown 有损导出说明、可恢复包与附件清单；外部依赖是否打包清楚显示 |

## 5. 首版之外

P1：完整 Markdown 源编辑、更多 Office provider、复杂表格、更多引用行为、数据集关系/公式、简单插件沙箱、公共发布页和访客分享。具体优先级以首版用户反馈重排。

专项：Word/Excel/PPT 领域完整多人编辑、记录字段级权限/大规模多维表格、完整思源 AV/SQL/图谱/闪卡/插件生态、任意低代码应用、媒体专业编辑及其协作。平台合同首期预留，功能不计入 18–28 周估算。

## 6. 关键用户流程

| 流程 | 正常结果 | 失败/边界 |
| --- | --- | --- |
| 新建并分享 | 创建对象 → 写作 → 邀请已认证协作者 → 同段协作 | 无权限/配额/服务故障不创建伪成功资源 |
| 插入 Office 页 | 选择受权资源 → 选页/区域与版本 → 插入 → 显示来源 | provider 不支持则明确原因；转换中可取消；不能随便用截图代替真实来源 |
| Agent 汇总 | 选择目标/来源 → 指令 → 草稿或受权提交 → 查看来源与修改 | 来源不可读、目标已改、授权到期分别反馈；已提交与未提交清楚区分 |
| 构建任务应用 | 选模板 → 新建或绑定数据集 → 选字段 → 发布实例 | 不支持字段/权限/定义版本时阻止启用，不污染原文档 |
| 离线退出重开 | 本机持久 → 退出 → 重开恢复 → 联网追赶 | 本机写失败时显示错误与可恢复路径，不显示已保存 |
| 恢复历史 | 预览指定版本 → 明确恢复对象范围 → 建新恢复版本 | 不自动回滚实时引用对象；旧离线改动成为待处理草稿 |

## 7. 权限与角色

Owner 管分享/对象生命周期，Editor 编辑受支持内容，Commenter 阅读/评论，Viewer 只读。具体权限仍由既有平台账户/ACL 裁决，不在客户端单独维护第二份授权表。

Agent 作业使用委托的对象集合、能力和期限；用户可查看作业来源并停止后续操作。应用实例只得到声明的数据绑定和操作范围。首版不提供公共匿名协作、字段级 ACL、原端到端加密自动延续的承诺。

## 8. 内容与状态表达

标题栏只显示用户有意义的状态：“已保存到本机”“待同步”“云端已确认”“保存失败”“只读”“访问已撤销”。Office 块显示来源、固定/实时绑定和实际预览模式；不把 ABI、CRDT、epoch 等实现术语放入普通操作流程。

破坏性操作区分移除引用与删除来源。转换显示具体损失项，允许保留原件。Agent 生成的草稿/建议有来源和状态，不能在未提交时伪装为团队已接受结果。

## 9. 成功指标与性能目标

以下是待验证目标，不是历史测量结果：

| 指标 | 0.1 目标及口径 |
| --- | --- |
| 首次任务成功率 | 试用用户按主线完成新建/插入/Agent/共享任务，至少 90%；样本与步骤在试用前冻结 |
| 恢复可靠性 | 故障注入语料中已明确本机持久的正文操作全部可恢复；任何数据丢失阻断发布 |
| 协作正确性 | 固定并发操作集及随机序列语义收敛，无环/单父/权限等不变量通过 |
| 本地输入 | 参考设备与固定内容集，输入响应 p95 < 50 ms |
| 远端可见 | 正常 50 ms RTT、5 人场景，p95 < 500 ms；断网不计正常时延但测恢复 |
| 文档重开 | 1000 块缓存 warm open p95 < 2 秒；cold 下载/核心初始化单独统计 |
| 三端覆盖 | macOS、Android/iOS 真机、目标 Web 浏览器关键流程全部有证据 |
| 扩展韧性 | 未安装/旧版本/崩溃应用块不丢载荷，不影响其他基础块读写 |

G0 以真实设备冻结基准。10000 块、10 人、多个 Office/媒体块作为压力与退化测试；内容大小、设备/浏览器/网络和缓存条件必须随结果记录。未达目标时给出限制与修复，不能更换测试口径伪通过。

## 10. 产品发布门槛

SD-01 至 SD-17 的限定范围有实现与验收证据；关键保存/恢复/越权/数据破坏缺陷为零；真实三端关键流程通过；能力表准确；源数据迁移/回退演练和适用许可材料齐全。按钮与静态截图不作为能力完成的证据。

## 12. v1.2 编辑与协作体验门槛

首版 SD-02 的“基础写作”必须闭环：样式/选区格式、列表/任务、代码/公式、基础表格、统一插入目录、段落移动/移除与撤销；工具栏、上下文菜单和快捷键共用领域命令。Markdown 快捷输入不能产生第二份独立正文。

SD-03/05/13/15 的“协作”必须闭环：真实在线人/远端位置、正文授权、选区/块评论及回复、解决/重开、提及通知、历史快照/操作记录/评论历史。评论者与只读者在原始更新入口也不可越权；连接中断、目标删除和权限撤销均有明确反馈。

当前可点击稿只验证其中部分交互，详情见 FA-01–FA-14；未覆盖项不能被原型检查自动判定通过。复杂表格、Office 全域多人编辑、贡献比例统计与公共发布仍按原优先级，不因参考 WPS 而整体进入 P0。

冻结释义：首版标题编辑 H1–H3；H4–H6 为后续增强。规范中的下划线、高亮等基础格式纳入 SD-02；字号/颜色按三端可用能力表开放。冻结的是正式产品行为，原型未覆盖项继续按 FA/AC 台账实现，不能静默删除。
