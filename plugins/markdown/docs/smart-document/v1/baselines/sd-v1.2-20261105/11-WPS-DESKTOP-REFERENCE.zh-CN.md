## 2. 本轮已经完成的对齐

以内容编辑为默认工作面：标题/共享 → 文档菜单 → 常用格式工具 → 目录/连续内容流/可关闭上下文侧栏 → 状态栏。Agent 按需打开；Host 全局资源树不在内容插件内重复创建。

交互覆盖：文字选区格式、段落样式与目录联动、基础表格、任务、`/` 搜索插入、段落移动/复制/移除、稳定链接示例；成员位置、分享角色、评论/回复/解决/重开、版本预览/恢复、协作记录；离线与只读状态；独立来源引用；Agent 冲突重读。

这些是 `MUSE + SIM` 交付；其中部分入口和行为有 `DOC` 依据。菜单顺序、图标、几何、面板宽度和“文件/编辑/插入/格式/查看”分类是待评审方案，不声称逐项观察自指定页面。既有 v1.1 工作区布局保留为历史行为试验。

## 3. 仍需补证的视觉/行为差异

| 项目 | 当前提案 | 指定页核对项 |
| --- | --- | --- |
| 功能区 | 单行菜单 + 紧凑常用工具 | 实际入口顺序、分组、溢出与上下文变化 |
| 编辑区 | 连续流、840px 最大页宽、可收起目录 | 实际页宽、背景、字号、标题元信息、块间距 |
| 选区/段落 | 选区工具、左侧柄、右侧评论 | 浮动定位、拖拽反馈、跨块选择、表格工具 |
| 协作 | 头像/位置、共享角色、评论侧栏 | 实际成员入口、光标呈现、侧栏随选区行为 |
| 历史 | 文件入口、右侧版本/记录、原位只读预览 | 具体菜单和新标签预览行为 |
| 样式 | Muse 主题，浅/深色 | 指定参考页的实际配色与尺寸 |

不能从 WPS 的外观推断其 CRDT/OT 算法。Mobile 本轮仅验证窄屏降级；不把桌面压缩版当作手机最终视觉稿。
